# Links

Link everything Eduardo could want to check, the first time it appears in an answer:

- Codebases: the GitHub repo, and the folder or file when the point is about one (`https://github.com/OutSystems/<repo>/tree/<branch>/<path>`).
- Teams: the GitHub team page (`https://github.com/orgs/OutSystems/teams/<slug>`); find the slug through the repo's `CODEOWNERS` or `gh api orgs/OutSystems/teams/<slug>`.
- Technical concepts and third-party tech (Kubernetes features, Firecracker, Envoy, AWS services): the official docs page.
- Tickets, Confluence pages, Slack messages, PRs, pipeline runs: their URLs.

Never invent a URL. Check that it exists (`gh`, the source you read it from) before linking. When none can be checked, name the thing without a link and say so.
