# Eduardo's terminal

- Eduardo's terminal is PowerShell 7 (`pwsh`). Write every command meant for him to run as PowerShell: Windows paths (`C:\git\...`, not `/c/git/...`), `&` to run an executable by path, `$env:NAME = 'value'` for environment variables, one command per fenced `powershell` block.
- Your own Bash tool stays Git Bash; this rule covers only the commands you hand to Eduardo.
