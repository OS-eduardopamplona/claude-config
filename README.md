# Claude Config

Personal [Claude Code](https://docs.anthropic.com/en/docs/claude-code) configuration files.

## Usage

These files live in `~/.claude/` and are automatically picked up by Claude Code. To use them, clone this repo into your home directory:

```bash
git clone git@github.com:EduardoPamplona/claude-config.git ~/.claude
```

Or cherry-pick individual files into your own `~/.claude/` setup.
